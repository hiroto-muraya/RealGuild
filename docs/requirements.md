## 1. 目的

RealGuild は、勉強・運動・仕事・趣味といった日々の努力を「クエスト」として記録し、達成するたびに経験値を獲得してキャラクターが成長するアプリです。努力の積み重ねを目に見える形にし、**続ける楽しさ**を提供します。

コンセプト: **「現実の努力を、冒険の成果に。」**

### 想定ユーザー
- 勉強・運動・資格取得などの習慣を続けたいが、モチベーションを保つのが難しい人
- ゲームが好きで、成長が数字や演出で見えると頑張れる人

### 成功の基準（MVP）
- ユーザー登録からクエストの作成・達成・レベルアップまでを、迷わず一通り体験できる
- 毎日開きたくなる手軽さがある（1 回の記録が数タップで終わる）

---

## 2. 開発の範囲（MVP と将来の拡張）

1〜2 か月で完成させるため、機能を **MVP（最初に作る最小限の機能）** と **将来の拡張** に分けます。

### MVP に含める機能

| ID | 機能 | 概要 |
|---|---|---|
| F1 | アカウント | 新規登録・ログイン・ログアウト（メールアドレスとパスワード） |
| F2 | キャラクター | 登録時に 1 体作成する。名前・レベル・経験値・能力値を持つ |
| F3 | クエスト管理 | クエストの作成・編集・削除・一覧表示 |
| F4 | クエスト達成 | 達成ボタンで経験値を獲得し、レベルアップや能力値の上昇が起きる |
| F5 | ホーム画面 | キャラクターの状態、今日のクエスト、経験値バーを表示する |
| F6 | 冒険の記録 | 達成履歴の一覧と、簡単な集計（今週の達成数など） |
| F7 | 配色の切り替え | 3 つの配色（勇者の夜 / 草原 / クラシック）から選べる |

### 将来の拡張（MVP には含めない）

| 候補 | 内容 | MVP から外す理由 |
|---|---|---|
| 称号・実績 | 「7 日連続達成」などの条件で称号を獲得する | MVP の完成後に追加しやすい |
| 連続達成（ストリーク） | 毎日続けた日数を表示し、ボーナスを与える | 同上 |
| ゴールド・アイテム・装備 | 報酬で装備を買い、見た目が変わる | 設計と画像素材の負担が大きい |
| パスワード再設定 | メールで再設定用のリンクを送る | メール送信サービスの導入が必要 |
| Google ログイン | 外部アカウントでログインする | Identity に後から追加できる |
| ギルド・フレンド | 他のユーザーと協力・競争する | 機能の規模が大きい |
| 通知・PWA 化 | リマインド通知、ホーム画面へのインストール | 後から追加できる |

## 3. 機能要件（MVP）

### F1 アカウント
- メールアドレスとパスワードで新規登録・ログイン・ログアウトができる
- ログイン状態は Cookie で保持する（ASP.NET Core Identity）
- ログインしていないと、ログイン画面以外は表示できない
- パスワードは 8 文字以上とする（英数字を含む）

### F2 キャラクター
- 新規登録時にキャラクター名を入力し、キャラクターを 1 体作成する（1 ユーザー 1 体）
- キャラクターの属性:
  - 名前、レベル（1 から開始）、累計経験値
  - **能力値（4 種類）**: クエストのカテゴリと対応させる

| カテゴリ | 対応する能力値 | 例 |
|---|---|---|
| 勉強 | 知力（INT） | 読書、資格の勉強、語学 |
| 運動 | 体力（STR） | 筋トレ、ランニング |
| 仕事 | 技量（DEX） | 業務、副業、作業 |
| 趣味 | 感性（CHA） | 楽器、絵、料理 |

### F3 クエスト管理
- クエストの項目:

| 項目 | 必須 | 内容 |
|---|---|---|
| タイトル | ○ | 例: 「英単語を 30 個覚える」 |
| 説明 | | 自由記述 |
| カテゴリ | ○ | 勉強 / 運動 / 仕事 / 趣味 |
| 難易度 | ○ | 5 段階（★1〜★5） |
| 種類 | ○ | 単発 / デイリー（毎日）/ ウィークリー（毎週） |
| 期限 | | 単発クエストのみ設定できる |

- 一覧はカテゴリ・状態（未達成 / 達成済み）で絞り込める
- デイリー・ウィークリーのクエストは、日付・週が変わると再び達成できるようになる
- 削除しても、過去の達成記録と獲得した経験値は残る

### F4 クエスト達成
- 「達成」ボタンで達成を記録する。経験値の計算は**バックエンドで行う**
- 獲得経験値は難易度で決まる（目安: ★1=10、★2=20、★3=40、★4=80、★5=150）
- 達成したクエストのカテゴリに対応する能力値も上がる
- 必要経験値に達するとレベルアップし、**レベルアップの演出**を表示する
- 押し間違えに備えて、**当日の達成は取り消せる**（経験値も戻す）
- 自己申告制とし、達成したかどうかの証明は求めない

### F5 ホーム画面
- キャラクター名、レベル、経験値バー（次のレベルまでの残り）、能力値を表示する
- 今日達成すべきクエスト（デイリー、期限の近い単発、今週のウィークリー）を表示し、その場で達成できる

### F6 冒険の記録
- 達成履歴を新しい順に表示する（日時、クエスト名、獲得経験値）
- 今週・今月の達成数と獲得経験値、カテゴリ別の割合を表示する

### F7 配色の切り替え
- 「勇者の夜」「草原」「クラシック」の 3 つの配色から選べる（既定は勇者の夜）
- ログイン画面、PC のサイドメニュー、ステータス画面から切り替えられる
- 選んだ配色はブラウザに保存する（端末ごとの設定。アカウントには保存しない）

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応端末 | **スマホと PC の両方を同じ優先度で対応する**（レスポンシブデザイン＝画面幅に合わせてレイアウトが変わる作り）。スマホでは片手で操作でき、PC では広い画面を活かした表示にする |
| 利用者 | **自分と知人のみ**（ポートフォリオとしても使う）。一般公開と収益化は行わないので、Vercel Hobby の非商用条件の範囲に収まる。新規登録は誰でもできるが、URL を広く公開はしない |
| 対応ブラウザ | Chrome / Safari / Edge の最新版 |
| 言語 | 日本語のみ |
| 費用 | 無料プランの範囲で運用する |
| 性能 | 通常の操作は 1 秒以内に応答する。ただし Render のスリープ明けの初回アクセスは遅くてもよい |
| セキュリティ | パスワードはハッシュ化して保存する（Identity が行う）。他のユーザーのデータにはアクセスできない。経験値などの計算をフロントに任せない |
| 保守性 | 機能の追加（称号・アイテムなど）がしやすい構造にする |
| デザイン | ファンタジー RPG の世界観（羊皮紙、紋章、ゲーム風のステータス画面など）。演出は軽快にし、操作の邪魔をしない |
